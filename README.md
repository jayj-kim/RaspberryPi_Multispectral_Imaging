# RaspberryPi Multispectral Imaging

Raspberry Pi 5 + USB 카메라 3대용 로컬 브라우저 프로그램.
현재 기능: 3채널 미리보기, 동시 녹화 시작/중지, 카메라별 AVI/시간 CSV 저장,
완료된 세션의 시간 기반 RGB 합성, 카메라별 4점 원근 정합, 회전·배율·X/Y 이동 설정 저장.
필터 장착 전에는 파장별 다분광 측정이 아닌 기능 개발용입니다.

## Raspberry Pi 설치

64비트 Raspberry Pi OS에서 저장소 디렉터리로 이동한 후 실행합니다.
OS 패키지의 OpenCV를 사용하므로 Pi에서 pip로 OpenCV를 빌드할 필요가 없습니다.

```bash
sudo apt update
sudo apt install -y python3-venv python3-opencv python3-numpy python3-flask v4l-utils ffmpeg
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
python -c "import cv2, numpy, flask; print(cv2.__version__)"
python app.py
```

라즈베리파이의 브라우저에서 `http://127.0.0.1:8000`을 엽니다.
다른 촬영 프로그램은 먼저 종료하세요. 서버 종료는 터미널의 Ctrl+C입니다.
서버는 로컬 접속만 허용하며 외부 인터넷에 노출하지 마세요.
다른 PC에서는 SSH 터널 `ssh -L 8000:127.0.0.1:8000 jonginkim@<Pi주소>`을
연결한 다음 해당 PC의 브라우저에서 같은 주소를 사용할 수 있습니다.

### 카메라 연결

`app.py`의 `DEVICES`는 다음 포트로 설정되어 있습니다.
USB 포트를 바꾼 경우 `ls -l /dev/v4l/by-path/`로 확인해 수정하세요.

| 이름 | /dev/v4l/by-path/ 아래 경로 |
|---|---|
| cam1 | platform-xhci-hcd.1-usb-0:2:1.0-video-index0 |
| cam2 | platform-xhci-hcd.0-usb-0:2:1.0-video-index0 |
| cam3 | platform-xhci-hcd.1-usb-0:1:1.0-video-index0 |

입력은 YUYV 640×480, 요청 프레임률 30fps입니다.
실행 시 수동 노출(`auto_exposure=1`, `exposure_time_absolute=4500`)을 적용합니다.
종료 후에도 설정은 남습니다. 필요하면 각 장치에
`v4l2-ctl -d /dev/video0 --set-ctrl=auto_exposure=3`처럼 자동 노출을 복원하세요.
권한 오류는 `id`로 video 그룹 가입 여부를 확인하세요. 필요한 경우
`sudo usermod -aG video "$USER"` 후 로그아웃/로그인하세요.
카메라가 끊기면 녹화가 종료되며, 연결을 복구한 후 프로그램을 재시작하세요.

## 사용 순서

1. 세 미리보기와 프레임률을 확인합니다.
2. 녹화 시작 → 녹화 중지. 먼저 짧은 10초 촬영으로 저장 성능을 확인하세요.
3. 완료된 세션을 선택하고 RGB 채널에 서로 다른 카메라를 배치합니다.
4. 정합 미리보기의 시간 슬라이더로 정지된 평면 대상이 보이는 장면을 고릅니다.
   아래 원본 cam1·cam2·cam3에서 같은 평면의 특징점 4개를 동일한 순서로 클릭합니다.
   예: 종이의 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래.
   마우스를 올리면 8배 돋보기·픽셀 격자·중심 십자선·원본 좌표가 표시됩니다.
   클릭은 십자선 중앙의 정수 픽셀을 선택합니다. 클릭 없이 마우스를 영상에 올려
   대략적인 위치를 잡은 뒤 방향키로 1픽셀씩 이동하고 Enter로 점을 저장할 수 있습니다.
   각 영상의 키보드 선택 시작 버튼 또는 Tab으로 영상에 포커스를 두어도 됩니다.
   Enter는 점 목록에 저장하며, 파일 보존은 합성 영상 저장 시 이루어집니다.
   점은 넓게 분포시키고 일직선·중복을 피하세요. 점 완성 시 원근 변환을 적용합니다.
   cam1이 기준이며 cam2·cam3의 배율·회전·원근 차이를 함께 보정합니다.
   필요하면 추가 회전·배율·X/Y로 미세 조정하세요. 원근 보정 → 회전/배율 → 이동 순서입니다.
   잘못 클릭한 점은 마지막 점 취소 또는 점 초기화로 다시 선택합니다.
5. 정렬이 맞으면 합성 영상 저장을 누릅니다.
6. `captures/<세션>/composite.avi`를 VLC 등에서 확인합니다.
   합성은 동기 처리이므로 완료까지 기다리세요. 긴 영상은 시간이 걸립니다.

세션마다 `cam1~3.avi`(MJPEG), `cam1~3.csv`, `session.json`을 저장합니다.
합성 후 `alignment.json`과 `composite.avi`가 추가됩니다.
재합성은 이 두 파일을 덮어씁니다. 중요한 결과는 별도 복사하세요.
합성 완료 시 대응점과 미세 조정값을 alignment.json에 보존하며, 세션을 다시 선택하면 복원합니다.
합성을 저장하기 전의 편집값은 페이지 새로고침 시 사라집니다.
원근 변환의 결과 중 원본 밖 영역은 검은색으로 표시됩니다.
저장 위치는 `python app.py --output /원하는/디렉터리`로 변경합니다.
저장 공간을 확인하세요. MJPEG 인코딩과 디스크 성능은 실제 Pi에서 검증해야 합니다.

## 필터 없는 영상의 자동 정합 검증

1. 세 카메라가 같은 평평한 인쇄물·포스터를 보도록 촬영합니다. 무늬가 없는 벽,
   반복 격자만 있는 장면, 흔들린 장면, 움직이는 물체는 피하세요.
2. 완료 세션을 선택하고 시간 슬라이더로 선명한 정지 장면을 고릅니다.
3. **선택 장면 자동 정합**을 누릅니다. ORB 특징점 매칭과 RANSAC으로
   cam2·cam3을 cam1에 맞추는 두 원근 변환을 계산합니다.
4. 성공하면 두 변환을 함께 적용하고 미세 조정값은 중립값으로 초기화합니다.
   특징점 수·유효점 비율·중앙 재투영 오차·특징점 분포를 표시합니다.
   점이 적거나 한곳에 몰리거나 오차가 큰 결과는 거부하며 기존 설정을 유지합니다.
5. 중첩 윤곽을 확인하고 다른 시간에서도 맞는지 슬라이더로 검사하세요.
   수치가 좋아도 특정 평면만 맞거나 반복 무늬를 잘못 맞출 수 있습니다.
   필요하면 **자동 정합 전 설정 복원**으로 직전 설정을 되돌립니다.
6. 합성 영상 저장을 누르면 계산한 제어점과 설정이 alignment.json에 저장됩니다.

자동 정합 후 원본 위 4점은 실제 매칭 특징점이 아니라 계산한 변환을 표현하는
제어점입니다. 수동 점 선택으로 다시 수정할 수 있습니다.
이 단계는 **선택한 한 프레임에서 구한 고정 변환**을 검증합니다.
이동 중 대상 거리·평면이 변하면 아래 프레임별 자동 정합 모드를 사용할 수 있습니다.
현재 신뢰도 수치는 추정에 사용된 대응점에 대한 지표이며 장면 전체 정확도를 보장하지 않습니다.
필터 장착 후 파장별 외형 차이에서는 ORB가 실패할 수 있어 별도 검증이 필요합니다.

## 프레임별 자동 정합 (저장 영상)

1. 먼저 짧은 5~10초 영상으로 확인합니다. 필요하면 수동 4점 정합이나
   선택 장면 자동 정합으로 초기 보정값을 준비합니다.
2. **프레임별 자동 정합 (저장 영상 후처리)**을 체크하고 합성 영상 저장을 누릅니다.
3. 진행 프레임 수, 자동 정합 성공 수, 대체값 사용 수를 화면에서 확인합니다.
   Raspberry Pi에서 매 프레임 특징점 검출은 오래 걸릴 수 있습니다.
4. 결과 `composite_dynamic.avi`를 확인합니다. 기존 `composite.avi`는 보존합니다.
   같은 모드를 재실행하면 해당 모드 결과와 진단 파일을 덮어씁니다.

각 출력 시점에서 시간상 가장 가까운 세 원본 프레임을 고르고 ORB/RANSAC으로
cam2·cam3을 cam1에 맞춥니다. 두 카메라 모두 품질 검사를 통과한 경우에만
새 변환을 함께 적용합니다. 안정화 강도에 따라 투영된 모서리 위치를 저역통과 필터로 처리합니다.

| 모드 | 현재 추정 반영 | 미세 변화 유지 범위 |
|---|---:|---:|
| 강하게 | 15% | 1.0px |
| 균형 (기본) | 30% | 0.7px |
| 빠르게 | 60% | 0.3px |

유지 범위 이내 변화는 직전 값을 그대로 사용합니다. 큰 변화(모서리 이동 30px 초과)는
연속 3회 유사한 추정(모서리 차이 8px 미만)이 확인될 때까지 보류합니다.
확인된 급변은 새 값으로 재획득하므로 그 순간 화면이 바뀔 수 있습니다.
빠른 실제 움직임도 급변으로 판단할 수 있으며, 강한 안정화는 추종 지연과 정합 오차를
늘릴 수 있습니다. 먼저 균형으로 비교하고 떨림이 크면 강하게, 추종이 늦으면 빠르게를 선택하세요.
이 기능은 정합 변환의 떨림을 줄이며 cam1 영상 자체의 흔들림을 제거하지 않습니다.
회전·배율 미세 조정과 X/Y 이동은 자동 변환 위에 적용되므로 특별한 목적이 없다면
미세 조정을 0도·1배·0픽셀로 두세요. 첫 성공 전 대체값은 현재 4점 설정과 미세 조정입니다.

정합 실패 시 직전 유효값을 유지합니다. 한 번도 성공하지 못했다면 초기 설정을 사용하며,
초기 설정도 없다면 항등 변환(정합 없음)입니다. 대체값을 사용한 프레임도 영상에 포함되므로
**파일 생성 완료가 모든 프레임의 정합 성공을 뜻하지 않습니다.**
전체 실패 시 결과에 경고를 표시합니다. 장기간 실패하면 영상이 계속 어긋날 수 있습니다.

- `registration_dynamic.jsonl`: 프레임 번호, 원본 시간, 상태(`estimated`,
  `fallback_previous`, `fallback_initial`), 실패 이유, 품질 지표, 적용 변환 행렬.
  `filter_state`는 초기 적용·미세 변화 유지·평활화·급변 보류·재획득 상태를 기록합니다.
- `registration_dynamic_summary.json`: 완료 여부와 성공/대체값 사용 집계.
  중단되면 `completed: false`가 남습니다. 중단된 영상은 완성본으로 사용하지 마세요.
- `alignment.json`: 초기 보정값과 프레임별 모드 선택을 보존합니다.

중첩 미리보기는 현재 고정 보정값을 보여주며 동적 결과는 저장된 영상을 확인해야 합니다.
이 기능은 후처리이며 실시간 합성은 아닙니다. 시간 차이, 렌즈 왜곡, 깊이별 시차를
해결하지 않으며, 하나의 평면이 지배적인 장면에서 먼저 검증하세요.

## 시간 및 정렬의 한계

CSV는 프레임 수신 직후의 호스트 단조 시각이며 센서 노출 시각이 아닙니다.
합성은 공통 촬영 구간에서 cam1의 시각마다 가장 가까운 다른 카메라 프레임을 선택합니다.
이는 하드웨어 동기화를 보장하지 않으며 버퍼 지연·움직이는 물체의 오차가 남습니다.
AVI는 고정 프레임률 30으로 기록하므로 드롭 시 원본 재생 시간이 실제와 다를 수 있습니다.
합성에서는 CSV를 사용하지만 출력 역시 중앙 프레임 간격을 사용한 고정 프레임률입니다.
현재 정렬은 4점 원근 변환과 회전·배율·평행 이동을 지원합니다.
카메라별 렌즈 왜곡 보정(체커보드 캘리브레이션), 시간 오프셋 수동 보정,
실시간 합성, 저장 공간 감시, 자동 재연결은 후속 구현 대상입니다.
단일 평면 정렬로 서로 다른 거리의 물체에 생기는 시차를 모두 없앨 수는 없습니다.

## 하드웨어 없는 개발 및 테스트

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest -v test_workflow.py
python app.py --demo
```

DEMO는 가상 영상입니다. 실제 카메라 성능을 검증하지 않습니다.
클라우드 검증에서는 녹화·시간 CSV·합성 파일 디코딩·채널 출력·요청 검사를 실행합니다.
실제 Pi에서 세 대 동시 수신 약 30fps는 확인했으나 이 프로그램의 실제 녹화 성능은 별도 확인해야 합니다.
