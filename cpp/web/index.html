cam2 X  Y  회전(도)  배율

체크하면 각 프레임에서 두 카메라를 다시 정합합니다. 실패하면 직전 유효값, 첫 성공 전에는 현재 수동 보정값을 사용합니다. 처리 시간이 늘어납니다. 미리보기는 현재 고정 보정값을 표시합니다.




비교할 때는 기존 방식 + 화면 전체 흔들림 완화 끄기로 시작하세요. 세션을 선택할 때 이 두 항목은 안전한 기본값으로 초기화됩니다.




강한 안정화는 변화에 늦게 반응할 수 있습니다. 큰 급변은 연속 3회 확인 후 적용합니다. 위 강도는 채널 정합값만 조절합니다. 화면 전체 흔들림은 아래 옵션을 사용하세요.




저장 영상의 앞뒤 보정값을 함께 평활화합니다. 대상 영역을 지정할 필요가 없습니다. 분석 후 영상을 다시 읽어 저장하며, 원본 cam1의 움직임은 유지합니다. 큰 창은 거리 변화에 따른 정합 정확도를 낮출 수 있습니다.




프레임별 정합 모드에서 사용합니다. cam1의 움직임을 추정해 RGB 전체에 동일한 이동을 적용합니다. 가장자리에 검은 영역이 생길 수 있으며 회전·확대 흔들림은 보정하지 않습니다.




전역 변환 후 DIS 광학 흐름으로 cam2·cam3을 위치별로 보정합니다. 어두운 영역·가림 경계에서 잘못 변형될 수 있습니다. 검사 영상의 흰색은 왕복 일관성 통과, 검은색은 미검증 영역입니다. 검은 영역도 합성에는 근사값으로 포함되므로 정량 측정용으로 그대로 신뢰하지 마세요. 처리 시간이 늘어납니다.




출력: 고정 정합은 composite.avi, 기존 방식은 composite_dynamic.avi이며, 실험 추적은 _tracking, 전체 안정화는 _stabilized, 시간축 평활화는 _smooth 접미사가 붙습니다. 4점 원근 변환과 회전·배율·이동을 저장 영상에도 동일하게 적용합니다. 정밀 동기화·렌즈 왜곡 보정·실시간 합성은 후속 기능입니다.
